# Artale 闇黑龍王 · 本體閃招練習

楓之谷 Artale 闇黑龍王本體階段的單機閃招練習網頁。

## 功能

- 本體 8 部位攻擊機制練習（腳踩、紅咬、噴火、黑鎖鏈、左右手、翅膀等）
- 可自訂按鍵
- 平台微調編輯器（拖曳、刪除、設為預設）
- 紅咬鎖定玩家位置，約一人範圍，跳躍可躲

## 使用方式

1. 用瀏覽器開啟 `index.html`
2. 地圖下方按 **開始練習**
3. 按 **E** 或左側 **進入微調模式** 可調整平台位置

## 檔案

- `index.html` — 主頁
- `style.css` — 樣式
- `game.js` — 遊戲邏輯
- `static/backgurend.png` — 背景圖

## GitHub Pages（可選）

若要用 Pages 發布，在 repo Settings → Pages → Source 選 `main` 分支 `/ (root)` 即可。
